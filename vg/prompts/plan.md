## Что нужно выдать

Только чистый JSON-объект, без текста вокруг и без markdown-обертки:

    {
      "videos": [
        {
          "id": "01",
          "title": "рабочее название ролика",
          "idea": "одна-две фразы: главная мысль и чему научится зритель",
          "hook": "первая фраза-крючок для первых двух секунд",
          "next": "одна фраза-тизер следующего ролика, у последнего пустая строка"
        }
      ]
    }

## Правила

- Ровно {{COUNT}} роликов, id по порядку: 01, 02, и так далее (две цифры).
- Каждый ролик самодостаточен и понятен без просмотра остальных.
- Ролики идут по нарастающей: от базового к более сложному, без повторов между роликами.
- hook задает интригу или вопрос, а не называет тему сухо.
- next связывает ролик со следующим и подходит для финального призыва.
- Буква ё запрещена, заменяй на е.
- Никаких эмодзи.

Выведи только JSON.
