{MISSING_ITEM}

Описание выше задает смысл и внешний вид. Собственные параметры бери только из поля states.
Параметры x, y, alpha, scale, glow, theme никогда не объявляй, даже если они где-то упомянуты: их задает движок.
Если states пуст, объяви 1-2 параметра, которые меняют главное состояние предмета. Параметров "про запас" не делай: каждый объявленный параметр обязан заметно менять картинку (проверка сравнивает кадры при крайних значениях).

## Контракт
Файл начинается ровно с этих импортов (других нет, кроме math и random):

    import math
    from ..core import obj, P
    from .. import mat

Регистрация:

    @obj("имя_snake_case", "описание одной фразой для подборщика, 10-140 символов", ["тег", "тег"], (ширина, высота),
         params={"level": P("num", 0.0, 0, 1, anim=True, desc="..."),          # kind: num | str | choice | bool
                 "mode": P("choice", "a", choices=["a", "b"], anim=True, desc="...")},
         anchors={"top": (0, -50)})   # смещение от центра рамки, нужно для связей
    def draw(c, p, t):
        ...

- c холст, рисуем в координатах рамки: (0, 0) левый верхний угол, (ширина, высота) правый нижний.
- p значения параметров (всегда есть p["theme"], используй col = mat.tc(p["theme"])), t время в секундах для зацикленных эффектов.
- Состояние объекта это чистая функция от p и t. Никакого накопления; случайность только с фиксированным seed.
- num-параметры обязаны иметь lo, hi и default внутри диапазона. Все, что меняется по ходу сюжета (уровень, режим, подпись), делай параметром с anim=True.
- Размер не больше 540x960, кадр должен рисоваться быстрее 0.3 с.
- Точки anchors лежат у края рисунка, не дальше 20 единиц за половину размера.

## Обязательные правила (нарушение отклоняется автоматически)

1. Цвет и прозрачность. Цвет это кортеж RGB из трех чисел.
   - В fill= у c.circle, c.rrect, c.poly и в цветах stops у mat.grad_rrect используй только НЕПРОЗРАЧНЫЕ цвета: mat.lite(col, k), mat.dark(col, k), col, (r, g, b) или mat.rgba(цвет, 255).
   - ЗАПРЕЩЕНО mat.rgba(цвет, число меньше 255) в fill= и в stops. Это самая частая ошибка: заливка с альфой не смешивается, а заменяет пиксели.
   - Альфа меньше 255 допустима только в outline=, в c.line, в аргументах c.shade_circle / c.shade_rrect / c.shade_poly и в параметре a у mat.shadow.
   - Нужна полупрозрачность (блик, затемнение, подсветка поверх): сначала нарисуй непрозрачную заливку, затем слой через shade_*:

         c.rrect(box, 8, fill=mat.dark(col, 0.7))              # непрозрачная основа
         c.shade_rrect(box, 8, mat.rgba(col, 90))               # прозрачный слой сверху

   - Прозрачность кортежем запрещена: цвет + (200,) дает кортеж из 5 чисел.
2. Рамки. Везде рамка это (x0, y0, x1, y1): левый верхний и правый нижний угол, а НЕ (x, y, ширина, высота). Собирай рамку только функциями mat.box_c(cx, cy, w, h) (по центру), mat.box_xywh(x, y, w, h) (по углу и размерам) или mat.box(x0, y0, x1, y1). Писать рамку кортежем из выражений запрещено.
3. Размер считай от рамки и от крайних значений параметров.
   - Сначала выбери size, потом рисуй внутри него. Размеры частей вычисляй из size и значения параметра, а не фиксированными числами.
   - Если число элементов зависит от параметра (ячейки, строки, столбцы), размер элемента вычисляй из доступной ширины, чтобы при максимуме параметра ряд помещался:

         W, H = 420, 120                       # те же числа, что в size
         n = max(2, min(8, int(round(p["cells"]))))
         gap, pad = 8, 14
         cw = min(66, (W - 2 * pad - gap * (n - 1)) / n)   # ширина ячейки

   - Проверка идет при значениях по умолчанию, минимумах и максимумах всех параметров. При каждом из них рисунок, включая свечение (c.glow расширяет форму на rad со всех сторон), тень (mat.shadow сдвигает вниз на dy и размывает на rad) и обводку, должен лежать внутри рамки size; выход допустим не более чем на 30 единиц. Безопаснее держать все внутри рамки с запасом в rad.
   - Рисунок занимает не меньше трети площади рамки при значениях по умолчанию.
4. Параметры. Имена латиницей в snake_case, варианты choice тоже латиницей (a-z, 0-9, _). Не называй параметр именем общего (x, y, alpha, scale, glow, theme). Параметр типа choice или bool обязан менять вид при смене значения, иначе не объявляй его. Параметр str (подпись) должен реально рисоваться через c.fit_text.
5. Текст только через c.fit_text, подписи короткие (до 10-16 символов), на русском.

## Материалы (используй их, чтобы объект совпал по стилю)
c.line(pts, col, w), c.circle(center, r, fill, outline, w), c.rrect(box, r, fill, outline, w), c.poly(pts, fill, outline, w), c.text(xy, t, size, fill), c.fit_text(xy, t, size, fill, maxw),
c.shade_circle(center, r, rgba), c.shade_rrect(box, r, rgba), c.shade_poly(pts, rgba),
c.glow(box, fn, rad, gain, sharp) свечение формы, которую рисует fn(sub) (внутри fn цвет только mat.rgba(col, 255));

mat.shadow(c, box, r, dy, rad, a), mat.led(c, xy, r, col, on), mat.file_card(c, cx, cy, w, h, col, kind),
mat.rgba(col, alpha), mat.box_c(cx, cy, w, h), mat.box_xywh(x, y, w, h), mat.box(x0, y0, x1, y1), mat.lite(col, k), mat.dark(col, k), mat.tc(theme).
Сигнатуры выше полные: других аргументов у методов c.* и mat.* нет. У shade_circle, shade_rrect, shade_poly нет outline и w; контур полупрозрачной фигуры рисуй через c.line(pts + [pts[0]], col, w).

## Стиль-гид
Темная сцена, предметы объемные: градиентная заливка (непрозрачные цвета), тонкая светлая обводка, мягкая тень под предметом, свечение только у активных частей (индикаторы, линии, выбранный элемент). Металл серый с горизонтальным бликом, стекло: темная непрозрачная основа плюс блик сбоку через c.shade_rrect. Один акцентный цвет темы на объект.

## Образец (рабочий объект: повтори его приемы)

```python
import math
from ..core import obj, P
from .. import mat


@obj("status_lamp", "Круглая индикаторная лампа: включается и меняет яркость, с короткой подписью",
     ["indicator", "icon"], (120, 140),
     params={
         "level": P("num", 0.0, 0, 1, anim=True, desc="яркость лампы, 0 погашена, 1 горит"),
         "label": P("str", "", anim=True, desc="подпись под лампой, до 10 символов"),
     },
     anchors={"top": (0, -70), "bottom": (0, 70)})
def draw(c, p, t):
    col = mat.tc(p["theme"])
    lv = p["level"]
    cx, cy, r = 60, 55, 36
    mat.shadow(c, mat.box_c(cx, cy + 6, 2 * r, 2 * r), r, 8, 10, 120)
    mat.grad_rrect(c, mat.box_c(cx, cy, 2 * r, 2 * r), r,
                   [(0, mat.lite(col, 0.2 + 0.5 * lv)), (1, mat.dark(col, 0.6))])
    c.circle((cx, cy), r, outline=mat.rgba(mat.lite(col, 0.5), 220), w=2)
    c.shade_circle((cx - 12, cy - 14), 9, mat.rgba((255, 255, 255), 90))
    if lv > 0.05:
        c.glow(mat.box_c(cx, cy, 2 * r, 2 * r), lambda s: s.circle((cx, cy), r, fill=mat.rgba(col, 255)),
               rad=14, gain=lv, sharp=False)
    if p["label"]:
        c.fit_text((cx, 122), p["label"][:10], 14, mat.rgba((240, 244, 250), 255), 110)
```

## Самопроверка перед ответом (выполни молча, исправь код, затем выведи)
- В коде нет ни одного mat.rgba(..., число меньше 255) внутри fill= и stops; такие альфы только в outline=, c.line, shade_*, mat.shadow.
- Все рамки собраны через mat.box_c, mat.box_xywh или mat.box.
- При максимальном значении каждого num-параметра рисунок (с тенью и свечением) помещается в size.
- Каждый объявленный параметр виден на картинке; общих параметров (x, y, alpha, scale, glow, theme) в params нет.
- Импорты ровно три, лишних нет; нет эмодзи и буквы е с двумя точками.
- Каждый вызов c.* и mat.* использует только аргументы из списка материалов, без выдуманных именованных аргументов.
