# Справочник объектов stage

Файл создается автоматически из реестра (команда в разделе 'Обновление справочника' руководства). Общие параметры есть у каждого объекта.

## Общие параметры

| параметр | тип | диапазон | меняется событием | описание |
|---|---|---|---|---|
| x | num | -300..840 | да | центр по горизонтали, 0..540 |
| y | num | -300..1260 | да | центр по вертикали, 0..960 (пол на 860) |
| alpha | num | 0..1 | да | прозрачность, 0 скрыт |
| scale | num | 0.2..3 | да | масштаб |
| glow | num | 0..1 | да | свечение вокруг объекта |
| theme | choice | cyan|violet|amber|green|rose|blue | да | цветовая тема, по умолчанию тема сцены |

## device

Устройство пользователя: ноутбук или телефон с экраном, на экране может быть файл, галочка или крест.

- теги: device, hardware
- размер рамки: 200x150
- точки привязки: bottom (0, 60), top (0, -62)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| kind | choice | laptop|phone | 'laptop' | нет | тип устройства |
| screen | choice | blank|file|ok|cross | 'blank' | да | что на экране: пусто, файл, галочка, крест |

## file

Карточка файла (документ, фото или таблица данных) с подписью-именем.

- теги: item, file
- размер рамки: 96x120
- точки привязки: left (-48, 0), right (48, 0)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| kind | choice | doc|photo|data | 'doc' | нет | вид файла |
| label | str |  | '' | да | имя файла под карточкой, до 14 символов |

## rack

Серверная стойка дата-центра с пятью блоками и мигающими индикаторами.

- теги: container, server, storage
- размер рамки: 110x220
- точки привязки: left (-55, 0), right (55, 0), top (0, -110)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| lights | num | 0..1 | 0.0 | да | доля активных блоков, 0 все спят, 1 все работают |

## link

Линия связи между двумя точками привязки объектов, по ней бегут светящиеся пакеты данных.

- теги: flow, connection
- размер рамки: 10x10
- точки привязки: нет
- рисуется на весь кадр (связь между объектами)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| from | str |  | '' | нет | начало, формат id.точка, например lap.bottom |
| to | str |  | '' | нет | конец, формат id.точка |
| progress | num | 0..1 | 0.0 | да | насколько линия прорисована |
| flow | num | 0..1 | 0.0 | да | интенсивность бегущих пакетов |
| bend | num | -200..200 | 0.0 | нет | изгиб линии в пикселях |
| reverse | bool |  | False | да | пакеты бегут от конца к началу |

## badge

Темная плашка-подпись с цветной точкой, для названий и коротких пояснений.

- теги: label
- размер рамки: 220x48
- точки привязки: bottom (0, 24), top (0, -24)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| label | str |  | '' | да | короткий текст плашки, лучше до 16 символов, длинный сильно уменьшается |

## room

Комната офиса в разрезе: стена, пол, окно, лампа и дверь; внутри ставят оборудование.

- теги: container, building
- размер рамки: 260x300
- точки привязки: door (95, 80), floor (0, 135), top (0, -150)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| lights | num | 0..1 | 0.0 | да | свет в комнате: лампа и окно, 0 темно, 1 ярко |
| door | choice | closed|open | 'closed' | да | дверь закрыта или открыта |
| label | str |  | '' | да | табличка над дверью, до 10 символов |

## lock

Навесной замок, закрытый или открытый: символ контроля и доступа.

- теги: icon, security
- размер рамки: 70x90
- точки привязки: bottom (0, 45), top (0, -45)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| locked | bool |  | True | да | true замок закрыт, false открыт |

## gauge

Полукруглый индикатор нагрузки с зонами от зеленой до красной и стрелкой.

- теги: meter, indicator
- размер рамки: 170x120
- точки привязки: bottom (0, 60), top (0, -60)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| value | num | 0..1 | 0.3 | да | уровень нагрузки, 0 пусто, 1 максимум |
| label | str |  | '' | да | подпись над шкалой, до 14 символов |

## plug

Вилка питания сверху от розетки: вставлена или выдернута, при выдергивании проскакивает искра.

- теги: power, icon
- размер рамки: 80x160
- точки привязки: bottom (0, 80), top (0, -80)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| plugged | num | 0..1 | 1.0 | да | 1 вилка в розетке, 0 выдернута |

## cloud

Объемное облако с подписью внутри: символ облачного сервиса и удаленных серверов.

- теги: icon, cloud
- размер рамки: 240x140
- точки привязки: bottom (0, 58), left (-110, 10), right (110, 10)

| параметр | тип | диапазон или варианты | по умолчанию | меняется событием | описание |
|---|---|---|---|---|---|
| label | str |  | '' | да | надпись внутри облака, до 10 символов |
| pulse | num | 0..1 | 0.0 | да | яркость облака, 0 спокойное, 1 светится |
